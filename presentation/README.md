# Presentation

Slide deck for the motion design course (~7 min) plus the separate deliverables (GIFs, PDF, link).
It's a self-contained HTML file with the real SVG animations playing live. The PDF is printed from the same file.

```sh
npm install        # once (playwright-core, uses the installed Google Chrome)
npm run all        # GIFs → deck → PDF → out/abgabe/ + out/After-Hours_Abgabe.zip
```

| Script               | Does                                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------- |
| `npm run gifs`       | `src/assets/animations/*.svg` → `out/gifs/*.gif` (plus `bar-hero.gif` = intro + loop)     |
| `npm run build [en]` | `src/slides.<lang>.html` → `out/praesentation.<lang>.html` + speaker notes                |
| `npm run pdf [en]`   | prints the deck (`?print` swaps motion for frame strips)                                  |
| `npm run package`    | collects PDF, HTML deck, GIFs, notes and the website link in `out/abgabe/`                |
| `npm run process`    | PNG sequences rendered from After Effects → cropped MP4s in `assets/process/` (see below) |

**Motion:** in present mode headlines, boxes, header lines and the little stars animate in with the curves of the After Effects
comps (see the motion section in `src/deck.css`). Print mode and `prefers-reduced-motion` show everything static.

**Presenting:** open `out/praesentation.de.html` in Chrome, `F` for fullscreen, arrows/space/clicker to navigate.

## Process material (`assets/`)

`ae/render-all-50fps.jsx` renders every draft/final pair from After Effects at 50 fps (run it on a copy of the
project, see the note in the script). `npm run process <framesDir> [--full=<width>] [--in-fps=<fps>]` turns the PNG
sequences into transparent WebM (VP9 with alpha), so the box colour always comes from CSS. The build pads each
pair to the same length plus a one-second hold, so draft and final loop in sync.

- `rocks-glass-draft`, `orange-draft`, `shaker-draft`: rendered from the comps of the same name in the After Effects
  project (copies of the finals, edited by hand/script, the finals stay untouched). Rocks glass: the liquid just fills
  up from the bottom once the glass has landed, no ice cube, peel or stars. Orange: easy ease on every key, the slice
  grows to 100% without overshoot, the slice lines fade in together. Shaker: only the shake timing differs.
  `--box-from` frames each draft exactly like its final.
- The logo has no draft (it was the first solution); its slide goes from the illustration straight to the final.
- `button-draft` is derived from the finished comp with the polish removed (`ae/rough-drafts.jsx`): every curve
  linear, the letter wave keeps all its keys, stars switched off.
- `bar-intro-ai-draft`: the bar scene was animated with Claude Code driving Illustrator and After Effects. The draft
  is regenerated by replaying the original build script from that session on auto-save 13.
- `process/bar-illustration.svg`: the static starting point of the bar scene.
- `static/`: the static illustrations (rocks glass, citrus, shaker, logo, button) exported as SVG from the Figma
  components; the build keeps only the component group and its gradients.
- `icons/`: app icons extracted from the installed apps with `sips`, for the timeline of the AI session.
- `figma/`: excerpts of the Figma design for the first slide.

**Comparison slides** build up one card at a time when presenting (illustration → first draft → final, the bar
without the illustration): the card in focus is centred, 20% bigger and on `surface/raised`, earlier cards wait at
half size on the side (drafts frozen on their last frame); the last step shows all cards looping in sync.

## English version

Copy `src/slides.de.html` to `src/slides.en.html`, translate it, then run `npm run build en && npm run pdf en`.
